# Remote Claude v0.3.0

## Claude 网页版窗口（重做）
- 不再加载 noVNC 页面：客户端自己画 VPS 画面，没有 VNC 控制栏。
- 自有工具栏：后退 / 前进 / 刷新 / 地址栏（可输入网址或搜索）/ 标签页列表 / 上传 / 下载。
- 一个窗口多个账号标签，每个账号独立的 VPS 屏幕和浏览器，可同时打开。
- 本地粘贴文字（中文、emoji、长文本）直接写进网页；本地输入法可用。
- VPS 网页里复制的内容自动回到本地剪贴板（支持中文）。
- macOS 上 ⌘C/⌘V/⌘A/⌘Z 映射为 Ctrl。
- 画面分辨率跟随窗口大小和屏幕缩放（Retina 清晰）。
- 文件：拖进画面、粘贴截图或点上传按钮，会自动放进网页的上传入口；网页里下载的文件可以“保存到本地”。
- 加载骨架屏、断线自动重连。
- 关闭窗口后自动关掉该账号的 VPS 浏览器（可在设置里改为保留）。

## 登录
- 登录窗口用同一画面，显示步骤进度；授权后自动读取授权码并提交，登录成功自动关闭。

## 对话
- 输入框支持粘贴 / 拖入 / 选择图片和文件：图片直接发给 Claude，其他文件上传到 VPS 并告诉 Claude 路径。
- Esc 中断生成。

## 账号与界面
- 头像外圈显示 5 小时额度用量（绿/黄/红）。
- 删除账号、退出登录、移除项目改用应用内确认框。
- 统一的提示条和错误提示。
- 快捷键：⌘/Ctrl+N 新会话、⌘/Ctrl+⇧B 打开网页版、⌘/Ctrl+⇧A 切换账号、⌘/Ctrl+, 设置。
- 外观：浅色/深色/跟随系统、对话字号、舒适/紧凑密度。
- 更新检查：填 GitHub Releases API 或 JSON 地址后，启动时自动检查。

## VPS 端（rcc）
- 远程画面改用 TigerVNC（Xvnc）+ matchbox，Chromium kiosk 模式 + DevTools 协议（只监听 127.0.0.1，经 SSH 隧道）。
- 新命令：desk / desk-open / desk-stop / desk-list / downloads / upload-dir；send 支持 --json 附件。
- 旧 VPS 需要在“设置 → 环境”点一次“开始”安装新依赖。
