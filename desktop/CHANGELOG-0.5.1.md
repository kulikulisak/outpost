# Outpost 0.5.1

- 审批不依赖 Claude 回复的语言：识别走 Claude Code 的结构化权限通道（工具名 + 参数），英文回复也照样弹出。
- Claude 的「选择题」（AskUserQuestion）现在能在电脑和手机上直接点选项回答，或写自己的想法；以前只能允许/拒绝，Claude 收不到答案。
- 方案确认（ExitPlanMode）显示方案内容，按钮为「开始做 / 再改改」。
- 命令说明是英文时不再直接显示英文，改用中文白话；省心模式会要求 Claude 用中文写命令说明。
- 手机推送：选择题和方案确认不再带「允许」按钮（避免误点），点开进入对话回答。
