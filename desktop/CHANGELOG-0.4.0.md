# Remote Claude v0.4.0 — 手机端

## 手机端（新）
- PWA 网页 App，iPhone / 安卓添加到主屏幕后全屏使用，浅色 / 深色 / 跟随系统。
- 会话列表：等待批准的置顶，运行中显示圆点和当前步骤，按项目分组，可搜索。
- 对话：Markdown、工具卡片、diff、任务进度（Todo）、思考中、随时停止；发图片和文件；语音输入（手机自带识别，只发文字）。
- 权限批准：底部弹层，允许一次 / 本会话都允许（Bash 按命令前缀）/ 拒绝并说明原因。
- 模型、思考强度、权限、账号一屏切换；运行中切换会接着同一段对话重启。
- 额度用完时一键换到别的账号继续，并重发上一条消息。
- 项目页：VPS 上所有项目和历史对话，可接着聊或开新任务。
- 网页版：在手机上操作 VPS 里的浏览器（多账号），触摸点击、网址栏、标签页、中文输入直接打进网页。
- 通知：需要批准 / 完成 / 额度用完；安卓可在通知上直接允许或拒绝。
- 隐私：照片上传前去掉 EXIF（手机端重编码 + VPS 端再清理）。

## VPS 端
- 新增 `rcc serve`（rcc-serve.mjs，零依赖）：只监听 127.0.0.1；设备配对（一次性配对码、每台手机独立密钥、输错限流）；SSE 实时推送；VNC WebSocket 代理；CDP 控制浏览器；Web Push（RFC 8291 / 8292，无第三方库）。
- `rcc pair`：终端里直接显示配对二维码。
- `rcc serve tailscale`：一键安装 Tailscale、登录、发布私网 HTTPS。
- `rcc answer --rule`：本会话内自动允许同类操作。
- 修复：切换浏览器缩放时偶发浏览器起不来（旧进程未退出就启动新进程）。
- 修复：VNC 频繁重连后 TigerVNC 把本机拉黑导致画面连不上。
- `vps-setup/install.sh`：不用电脑端也能一条命令装好。

## 电脑端
- 设置 → 手机：开启手机服务、一键设置 Tailscale、自定义 HTTPS 地址、显示配对二维码、管理已配对手机。
- 局域网入口：同一 Wi-Fi 下手机经电脑连到 VPS（不需要 Tailscale）。
- 检查更新默认指向 GitHub Releases。
