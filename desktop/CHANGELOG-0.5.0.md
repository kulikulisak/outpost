# Outpost 0.5.0 — 省心模式

给不写代码的人用的一版。默认开启，可在「设置 → 模型与对话」（手机：设置）里关掉。

- **每轮自动存档**：每发一条消息前，项目文件自动存一份（用的是独立的存档库，不碰你自己的 Git）。
- **撤销这一轮**：每轮结束显示「新建 2 个、修改 1 个文件」，一键恢复到这条消息之前；恢复前会再存一份，不会丢。Claude 会被告知文件已恢复。
- **大白话总结**：Claude 每轮最后用一两句话说做了什么、怎么看结果；读文件、跑命令等过程收进「做了 N 步」，想看再展开。
- **预览**：改了网页文件时出现「预览」按钮，电脑端弹出预览窗口，手机端在新页面打开（预览页面被隔离，碰不到 Outpost 的登录信息）。
- **权限弹窗说人话**：「Claude 想要安装需要的软件包，可以吗？」；删除文件、强推、sudo 等危险操作会标红提醒；命令细节默认收起。
- rcc 新命令：`restore`、`checkpoints`、`preview`；`start --simple`。
