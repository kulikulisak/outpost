# Outpost 0.7.0

- **链接卡片**：Claude 回复里的网址显示成卡片（标题、网站、图标、预览图）。预览信息在服务器上抓取，你的电脑和手机不会去碰那个网站。可以在本机打开、用服务器浏览器打开或复制。修好了电脑端点链接会让整个窗口跳走的问题。
- **服务器上的网页一键预览**：Claude 启动的 `localhost:端口` 页面直接显示「预览」按钮，电脑和手机都能打开。
- **文件卡片**：Claude 生成的 PDF、表格、图片、文档等显示成卡片，电脑端可以打开或保存，手机可以打开、保存或分享。
- **随手聊**：不用选项目，随便问、查资料、写东西（在服务器的 `~/chat` 文件夹里）。
- **/ 命令和 @ 文件**：输入框里打 `/` 用命令（如 `/compact`、你自己的命令和技能），打 `@` 搜索并引用项目里的文件。
- **关于我**：设置里写下 Claude 应该一直记得的事，所有对话、所有账号都会读到（服务器的 `~/.claude/CLAUDE.md`）。
- **定时任务**：每天、每周、每隔一段时间或某个时间点，让 Claude 自动做一件事。在服务器上运行，电脑和手机都关着也会做，做完推送到手机。
- **Claude 会用服务器浏览器**：需要登录网站、点按钮、填表时，Claude 会操作服务器上的 Chrome，你可以在「网页版」里实时看着。可在设置里关掉。
- **出错一键修复**：出错时用大白话说明，点「让 Claude 修好」就会接着处理。
- **手机通行密钥**：配对一次后在设置里添加通行密钥，以后换手机或清了数据，用 Face ID / 指纹就能登录（需要 https 地址）。
- **安卓 App**：Release 里有 `Outpost-0.7.0-android.apk`，打开后填你的服务器网址即可。安卓 App 里收不到后台通知，需要通知请用 Chrome 安装网页版。
